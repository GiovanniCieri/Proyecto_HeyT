# Demo web y consola

La web es una ampliación del ejercicio. Con ambos servicios levantados, abrir `http://127.0.0.1:8000/register`. El recorrido `/audit` explica cómo el agente encontró las discrepancias; ADMIN permite lanzar pruebas manuales y consultar sus trazas redactadas. La consola interactiva se abre con `scripts/console.cmd` en Windows o `bash scripts/console.sh` en macOS/Linux.

Las capturas muestran estados de la demo; las pruebas reproducibles del contrato están en [AUDIT_INDEPENDIENTE](AUDIT_INDEPENDIENTE/INFORME.md).
